Notes UX — Graphes admin

Écran concerné : partial kpi-charts / kpi-cards, utilisé par le super admin et le tableau de bord admin (superviseur).

Histogramme
  • Sélecteur Nombre / % à côté de Semaine / Mois / Année. Nombre par défaut.
  • Nombre : colonnes empilées, axe gradué automatiquement, total au-dessus de chaque colonne.
  • % : chaque colonne = 100 %, axe 0–100 %.
  • Infobulle : nombre et % dans les deux modes.
  • Choix non mémorisé : retour à Nombre à chaque chargement de page ; conservé pendant la navigation semaine ↔ mois ↔ année.
  • Texte explicatif sous le graphe supprimé ; titre fixe.
Camemberts
  • Valeurs uniquement dans la légende : rien d'écrit dans les parts (évite les chiffres illisibles sur les petites parts).
  • Le % apparaît au survol d'une part ou d'une ligne de légende ; la part se détache légèrement.
  • Clavier : Tab sur chaque part. Mobile : un appui sur la part.
  • Total concis sous le camembert : « Total 855 ».
Inchangé
  • Navigation année → mois → semaine par clic sur une colonne.
  • Export CSV : nombre et %, quel que soit l'affichage.
  • « Voir les données » : tableau replié, conservé pour l'accessibilité (lecture sans couleur, lecteurs d'écran).
Décisions validées
  1. Unité par défaut : Nombre.
  2. Pas de mémorisation du choix.
  3. Colonnes empilées en mode Nombre.
  4. Valeurs des camemberts dans la légende seulement.
  5. Total sous le camembert : oui, concis ; textes inutiles retirés.

Données agrégées uniquement, aucune donnée individuelle : pas de changement de périmètre d'accès.
